# 高中校园风的提示词生成规则

用于校园、青春回忆、毕业纪念等主题。先读取用户目标；年代、校服和画法可替换，不能把示例设定强加给所有校园任务。

## 从需求生成

1. 提取年代与地区、学生年龄、季节、校服、校园建筑、产品用途、屏幕比例和文字区域。缺项列假设。
2. 建角色与环境固定表，选择一张参考图统一发型、服装、窗框、建筑和画法。无参考图时不声称已建立一致性。
3. 根据用途选场景与镜头。入口用校门中远景，关系用纸条近景，对话用走廊中景，日常用食堂群像，时间变化用晚自习。可扩展球场、图书馆等新场景，延续固定表。
4. 每条输出完整设定、一个明确动作、镜头、光源、配色、少量道具和具体留白位置。母设定与变量合并后逐条给出完整提示词。
5. 配页面时另写实现提示词，定义图片裁切、标题和按钮、状态及交互。图中的文字使用后期排版。

## 五组已沉淀提示词

读取 ../../../themes/high-school-campus/README.md 的成组设定与图片，单条原稿见同目录 gate.md、note.md、corridor.md、canteen.md、night.md。这些是复刻模板，未逐条重新生成验证。

| 场景 | 生成时的关键约束 | 迭代检查 |
| --- | --- | --- |
| 校门 | 门框与树冠交代地点，人物及自行车在中部，底部道路留白 | 校门透视、手和车把、竖屏裁切 |
| 纸条 | 桌面近景，纸条无字，中景同桌，光线来自窗侧 | 手与纸张、桌面透视、留言区域 |
| 走廊 | 柱廊纵深、人物视线、连续墙面或阴影留字 | 消失点、人物比例、台词可读性 |
| 食堂 | 一桌人物关系明确、少量餐具、背景人群简化 | 手指、餐盘数量、遮挡关系 |
| 晚自习 | 暮蓝窗外与暖白室内，保持原校服与教室设定 | 窗框连续性、亮纸面、灯与文字 |

## 调用示例

使用 ui-scene-prompt-skill，为毕业纪念故事生成五组校园场景提示词。参考高中校园主题包，但改成北方秋季校园与红白校服。保留人物一致性，交替近中远景，分别给竖屏和横版卡片构图建议，输出完整提示词、页面实现提示词与逐轮修改清单。
